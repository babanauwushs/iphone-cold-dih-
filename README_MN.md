# Их Засаг Политехник коллежийн мэдээ, зарлалын модуль

Энэ модуль нь Flask аппад мэдээ, зарлал нэмэх, засах, нийтлэх, ноорог болгон хадгалах боломж нэмнэ. Өгөгдөл одоо байгаа SQLite сан (`instance/users.sqlite3`)-д хадгалагдана.

## 1. Файлууд

Төслийн бүтэц:

```text
app.py
news_integration.py
instance/
  users.sqlite3
templates/
  news_index.html
  news_detail.html
  news_manage.html
  news_form.html
```

`app.py`, `instance/users.sqlite3`-г устгах эсвэл солих шаардлагагүй. Өөрчлөлт хийхийн өмнө төслийн хавтсаа нөөцлөх нь зүйтэй.

## 2. Flask апптай холбох

`app.py`-ийн import хэсэгт:

```python
from news_integration import get_latest_news, init_news_database, news_bp
```

`app.config.update(...)`-ийн дараа blueprint-ийг бүртгэнэ:

```python
app.register_blueprint(news_bp)
app.add_url_rule(
    "/admin/news",
    endpoint="admin_news",
    view_func=app.view_functions["news.manage"],
)
```

Одоо байгаа `initialize_database()` дуудлагын дараа мэдээний хүснэгтийг үүсгэнэ:

```python
init_news_database(app)
```

Нүүр хуудсанд хамгийн сүүлийн мэдээг харуулахын тулд `render_home()`-д:

```python
context.setdefault("latest_news", get_latest_news())
```

Төслийн `app.py` файл эдгээр холболтыг агуулж байгаа.

## 3. Апп ажиллуулах

PowerShell дээр төслийн үндсэн хавтас руу орж, хамаарлыг суулгаад аппыг асаана:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Утсаараа ижил Wi-Fi сүлжээнээс нээхийн тулд аппыг компьютер дээр асаалттай байлгаад утасны browser-т `http://192.168.40.23:5000` хаягийг оруулна. Энэ нь зөвхөн тухайн дотоод сүлжээнд ажиллах холбоос бөгөөд компьютерын IP өөрчлөгдвөл `ipconfig` командаар шинэ `IPv4 Address`-ийг шалгаж, холбоос дахь IP-г солино. Windows Firewall хандалтыг асуувал зөвхөн хувийн сүлжээнд зөвшөөрнө. Энэ холбоосыг интернэтээр нийтэд түгээх холбоос гэж үзэж болохгүй.

## 4. Админаар нэвтрэх

Апп анх эхлэхдээ `admin1` хэрэглэгчийг `admin1` нууц үгтэйгээр үүсгэнэ. Сайтын баруун дээд талын **Админ самбар** товчоор нэвтрэх хуудас руу орно. Энэ анхдагч нууц үгийг зөвхөн хөгжүүлэлтийн орчинд ашиглана; нийтэд байршуулсан серверт хүчтэй нууц үг тохируулна:

```powershell
$env:FLASK_ADMIN_USERNAME = "admin нэр"
$env:FLASK_ADMIN_PASSWORD = "өөрийн хүчтэй нууц үг"
python app.py
```

Өөрийн админ нэвтрэх нэр, нууц үгийг тохируулсан тохиолдолд нууц үг 12–128 тэмдэгт байна. Тохируулсан хэрэглэгч өмнө нь бүртгэлтэй бол тухайн хэрэглэгчид админ эрх олгоно. Нууц үгээ эх код эсвэл нийтэд нээлттэй файлд бүү бич.

## 5. Хуудаснууд

- Нийтийн мэдээ, зарлал: `http://127.0.0.1:5000/news`
- Админы нэвтрэх: `http://127.0.0.1:5000/admin/login`
- Админы мэдээ удирдах: `http://127.0.0.1:5000/admin/news`

Нэвтэрсэн админ мэдээ эсвэл зарлал нэмж, засаж, нийтлэх, ноорог болгох, устгах боломжтой. Зөвхөн нийтэлсэн нийтлэлүүд нүүр хуудас болон нийтийн мэдээний жагсаалтад харагдана. Ноорог нийтлэлийн дэлгэрэнгүйг админ л үзнэ.

## 6. Өгөгдлийн сангийн хүснэгт

Модуль `news` хүснэгтийг эхлүүлэхдээ автоматаар үүсгэнэ. Өмнө байсан хүснэгтэд төрөл болон нийтлэлийн төлөвийн багана дутуу байвал өгөгдлийг устгалгүйгээр нэмнэ.

| Багана | Зориулалт |
| --- | --- |
| `title` | Гарчиг |
| `summary` | Товч агуулга |
| `body` | Дэлгэрэнгүй текст |
| `category` | `news` буюу мэдээ, `announcement` буюу зарлал |
| `is_published` | Нийтэлсэн эсэх; шинэ нийтлэл эхлээд ноорог байна |
| `created_at`, `updated_at`, `published_at` | Үүсгэсэн, зассан, нийтэлсэн огноо |

Нийтийн серверт байршуулахдаа `FLASK_SECRET_KEY`-г тогтвортой нууц утгаар тохируулж, HTTPS ашиглана уу.

## 7. Холбоо барих зурвас

Нүүр хуудасны “Холбоо барих” маягт нэр, имэйл, утас, зурвасыг SQLite сангийн `contact_messages` хүснэгтэд хадгална. Админ нэвтэрсний дараа `/admin/messages` хуудаснаас ирсэн зурвасуудыг уншиж, шаардлагатай бол устгана. Админ самбарт ирсэн зурвасын нийт тоо харагдана.
